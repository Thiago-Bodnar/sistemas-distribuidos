# corridas-distribuidas-api

## Como rodar este projeto

1. Instale o gerenciador [uv](https://github.com/astral-sh/uv):

```bash
pip install uv
```

2. Instale as dependências do projeto:

```bash
uv sync
```

3. Rode a aplicação FastAPI:

```bash
uv run fastapi dev
```

Pronto! A aplicação estará rodando.
